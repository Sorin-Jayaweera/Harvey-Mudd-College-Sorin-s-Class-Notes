
## Gravity Waves
$$
\begin{align}
\frac{ d ^{2}z_{p} }{d t^{2} } = \frac{g(\rho_{env} - \rho(z_{2} ) )}{\rho(z_{2} )} = g \frac{(T_{p} - T_{env}(z_{2} ) )}{T_{env}(z_{2} ) } \\
= g \frac{(\theta_{p} - \theta_{env}(z_{2} )  )}{\theta_{env}(z_{2} ) } \\
\theta(z_{2} ) = \theta(z_{1} ) + \left( \frac{ \partial \theta }{ \partial z }  \right)_{env}\Delta z \\ 
\end{align}
$$
In stable stratification, we are able to get waves with a natural frequency set by the N buoyancy frequency.

$$
\begin{align}
N^{2} \equiv  \frac{g}{\theta_{env} } \frac{ d \theta}{d z } _{env} 
\end{align}
$$
$N$ is the density gradient * g divided by a reference

because $z_{p}\approx \Delta z$

$$
\begin{align}
\frac{ d ^{2} z_{p} }{d t^{2} } = -\frac{g}{\theta_{env} } \left( \frac{ \partial \theta }{ \partial z }  \right)_{env} z_{p} = -N^{2} z_{p} \\
z_{p} = c_{1} \cos(Nt) + c_{2} \sin(Nt)    
\end{align}
$$
We have period on the order of $\frac{2\pi}{N}\approx 8 \text{ minutes }$.

The spatial wavelength would be
$$
\begin{align}
\lambda= \frac{3\pi (v)}{N}
\end{align}
$$
so for $V = 10 m s^{-1}$, this would be about $5 km$. 


## Wave generation from convective plumes

Look at internal wave generation by turbulent convection animation.

Take an unstable region, then a stable region above it. Turbulence in the unstable region will hit the stable one, causing waves to propagate in the stable region. 


## Internal waves over topography

Mountains push air parcels up, which ripples going up. This makes vertical displacement, which then propagates radially outwards. Moisture that was absorbed well in the atmosphere then condenses as the parcels rise. Lenticular clouds!



Dewpoint: the temperature a parcel must be cooled to to become saturate with waver vapour.
